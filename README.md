# Control de Asistencia - Prototipo Reto 0

Aplicación web desarrollada en Python con Flask y SQLite para el registro, edición, consulta y eliminación de asistencia de aprendices por fecha, con acceso exclusivo para el instructor.

## Estructura Inicial
```text
control-asistencia/
├── app/
│   └── main.py
├── templates/
│   ├── base.html
│   ├── login.html
│   └── asistencia.html
├── requirements.txt
└── README.md
```

## Requisitos y Ejecución
1. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
2. Iniciar la aplicación:
   ```bash
   python app/main.py
   ```
3. Acceder en el navegador a `http://localhost:5000`. Credenciales por defecto: `instructor` / `sena2024`.
